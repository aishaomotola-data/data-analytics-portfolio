# Project 2: Customer Behaviour Analysis

## Overview
Analysed customer purchasing behaviour, product performance,
and employee sales using the Northwind database in SQL Server.

## Tools Used
SQL Server | SSMS | T-SQL

## Dataset
Northwind Database — 91 Customers | 830 Orders | 2,155 Order Details

## Business Questions Answered
1. Which customers generate the most revenue?
2. What are the best selling products and categories?
3. Which regions drive the most orders?
4. How does monthly order volume trend over time?
5. Which employees handle the most revenue?
6. Who are the high value customers above average spend?

## Key Techniques Used
- JOINs across multiple tables
- GROUP BY with aggregations
- Subqueries
- CTEs (Common Table Expression)
- DATEDIFF and DATENAME date functions

## Key Findings
- Total revenue: $1,265,793.04
- Top customer: Quick-Stop (Germany) at $110,277.30
- Top category: Beverages
- Peak trading period: Q4 (Oct-Dec)
- Top employee: Margaret Peacock at $232,890.85 (18% of revenue)
- 30 of 91 customers (33%) are high value
