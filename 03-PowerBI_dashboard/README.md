# Project 3: PowerBI Interactive Sales Dashboard

## Overview
Built an interactive Power BI dashboard analysing Superstore 
sales performance across regions, categories and customers.

## Tools Used
Power BI Desktop | Power Query | DAX

## Dataset
Superstore Sales Dataset (Kaggle) — 10,000+ records

## Dashboard Features
- 4 KPI cards (Total Sales, Profit, Orders, Profit Margin)
- Sales trend line chart (monthly)
- Sales by category bar chart
- Sales by region donut chart
- Top 10 customers bar chart
- Geographic map by state
- Interactive year slicer filtering all visuals

## DAX Measures Created
- Total Sales
- Total Profit
- Total Orders
- Profit Margin %

## Key Findings
- Technology is the highest grossing category by revenue and profit
- West region leads all four regions in total sales
- California is the strongest individual state by revenue
- Sales and profit grew consistently year on year with 2017
  recording the highest performance across both metrics

## Recommendation
Prioritise investment in Technology products and increase marketing
in the West region and California. The West + Technology combination
represents the highest impact opportunity for continued growth.
