# Project 3: PowerBI Interactive Sales Dashboard

## Overview
Built an interactive Power BI dashboard analysing Superstore 
sales performance across regions, categories and customers.

## Tools Used
Power BI Desktop | Power Query | DAX

## Dataset
Superstore Sales Dataset (Kaggle) — 10,000+ records

## Dashboard Features
- 4 KPI cards (Total Sales, Profit, Orders, Profit Margin)
- Sales trend line chart (monthly)
- Sales by category bar chart
- Sales by region donut chart
- Top 10 customers bar chart
- Geographic map by state
- Interactive year slicer filtering all visuals

## DAX Measures Created
- Total Sales
- Total Profit
- Total Orders
- Profit Margin %
